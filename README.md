## 💡 How This Repository Works

To maintain clean versioning and secure source management, this repository acts as an **automated distribution endpoint**:

1. **Source Control (Private):** My resume source files (LaTeX, assets, and design templates) are managed in a private repository.
2. **CI/CD Compilation:** Whenever an update is committed to the private source, a custom GitHub Actions pipeline automatically builds the document into a high-quality PDF.
3. **Public Release Sync:** The compiled PDF artifact is securely published to this public repository as an official **GitHub Release**, tagged dynamically by build date (`vYYYY.MM.DD`).

```
┌─────────────────────────────┐
│  Private Resume Source Repo │
└──────────────┬──────────────┘
               │
               ▼  (GitHub Actions CI/CD)
┌─────────────────────────────┐
│    Compile LaTeX to PDF     │
└──────────────┬──────────────┘
               │
               ▼  (Publish via Secure Token API)
┌─────────────────────────────┐
│  Public Release (This Repo) │
└─────────────────────────────┘
               │
               ▼ 
[ Download Arpit_Mishra_Resume.pdf ]
```
